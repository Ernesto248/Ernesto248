Soy desarrollador full stack en Valencia, España. Diseño aplicaciones web para operaciones reales, desde la interfaz y las APIs hasta la integridad de datos, las automatizaciones y el despliegue. Trabajo principalmente con **TypeScript, Next.js, React y PostgreSQL**; también he desarrollado con **Java y Spring Boot**.

I build end-to-end web products for real operations. I am open to full stack opportunities in Spain and the EU.
